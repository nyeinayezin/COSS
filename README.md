# COSS
centre operation support system
This project will be a working feature demo and Proof of Concept (PoC) for a Center Operating Support System. Please note that this is not a fully developed, production-ready web application. Instead, it serves as a functional prototype designed to showcase how specific core workflows and administrative functions operate in a live environment.
 users might be admins can view /update/ create/delete all users roles, daily records, monthly salary/payroll/fee, inventory control, child and parent data, employee data, Lesson plans approval, proceed and release income/outcome
 parents for viewing child's record & daily routine, and payment due,  feedback/suggestions, enrolment <AFA> and request form for update kid's information,  records, can view news/events,
 teachers uploading/downloading Lesson Plans, achievements<for school success>/commitment<promoted position through yrs @school>/awards <dedicated teacher outstanding award/staff award>, proposals/feedbacks/advices/suggestions, students homework  <File upload>, record/data filling deals with child, can view news / events/ submitted homework
 general staff  achievements/commitment/awards, proposals/feedbacks/advices/suggestions, can view news / events
